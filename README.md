# GreekTax GR 🇬🇷

Φιλικοί υπολογιστές φόρων για την Ελλάδα — για μισθωτούς, ελεύθερους επαγγελματίες, επιχειρήσεις και όχι μόνο. Χτισμένο με **Next.js 16 + React 19 + TypeScript**.

## Υπολογιστές

| Εργαλείο | Τι κάνει |
| --- | --- |
| 💶 **Φόρος εισοδήματος** | Κλίμακα 2024/2025 (9–44%), μείωση φόρου μισθωτών ανά τέκνο, ανάλυση κλίμακας |
| 🧾 **Καθαρός μισθός** | ΕΦΚΑ 13,87% + παρακράτηση φόρου · μεικτά → καθαρά · κόστος εργοδότη |
| 💼 **Ελεύθερος επαγγελματίας** | Ελάχιστο τεκμαρτό εισόδημα (βάση €12.320), προσαυξήσεις μισθοδοσίας/τζίρου, προκαταβολή φόρου 100% |
| 🏢 **Εταιρεία** | Φόρος νομικών προσώπων 22% + παρακράτηση μερίσματος 5% |
| 🧮 **ΦΠΑ** | Πρόσθεση/απόσπαση ΦΠΑ 24/13/6% |

## Άμεση εκκίνηση

```bash
npm install
npm run dev
```

Άνοιξε το [http://localhost:3000](http://localhost:3000).

## Πλήρης εγκατάσταση

```bash
npm run build    # production build
npm run start    # serve the build
npm run lint     # ESLint
```

## Δομή

```
greektax/
├── app/            # App Router (layout, σελίδα)
├── components/     # Υπολογιστές + κοινά UI elements
├── lib/tax.ts      # Όλη η φορολογική λογική
└── globals.css     # Design system
```

## Σημείωση

Τα αποτελέσματα είναι **ενδεικτικά**. Ισχύουν οι κλίμακες του ν. 4172/2013 για το φορολογικό έτος 2025. Για την υποβολή της δήλωσης συμβουλεύσου επαγγελματία λογιστή.
