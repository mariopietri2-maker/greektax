## ✨ Υπολογιστές

| 🛠️ Εργαλείο | 📝 Τι κάνει |
| :--- | :--- |
| 💶 **Φόρος εισοδήματος** | Κλίμακα 2024/2025 (9–44%), μείωση φόρου μισθωτών ανά τέκνο, αναλυτική ανάλυση κλίμακας |
| 🧾 **Καθαρός μισθός** | ΕΦΚΑ 13,87% + παρακράτηση φόρου · μεικτά → καθαρά · κόστος εργοδότη |
| 💼 **Ελεύθερος επαγγελματίας** | Ελάχιστο τεκμαρτό εισόδημα (βάση €12.320), προσαυξήσεις μισθοδοσίας/τζίρου, προκαταβολή φόρου 100% |
| 🏢 **Εταιρεία** | Φόρος νομικών προσώπων 22% + παρακράτηση μερίσματος 5% |
| 🧮 **ΦΠΑ** | Πρόσθεση / απόσπαση ΦΠΑ σε ποσοστά **24% / 13% / 6%** |

### 💡 Χαρακτηριστικά

- ⚡ **Ζωντανά αποτελέσματα** — υπολογισμός τη στιγμή που πληκτρολογείς
- 🌗 **Dark mode** — ακολουθεί το σύστημά σου
- 🇬🇷 **100% στα ελληνικά** — φιλικό για κάθε χρήστη
- 📱 **Responsive** — λειτουργεί άψογα σε κινητό, tablet και desktop

## 🚀 Άμεση εκκίνηση

```bash
# 1. Εγκατάσταση εξαρτήσεων
npm install

# 2. Εκκίνηση του development server
npm run dev
```

Άνοιξε το **[http://localhost:3000](http://localhost:3000)** στο browser σου 🎉

---

## 📦 Πλήρης εγκατάσταση

```bash
npm run build    # 🔨 Production build
npm run start    # ▶️  Serve το build
npm run lint     # 🔍 ESLint
```
